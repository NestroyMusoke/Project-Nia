- Model terms: https://3d.nicovideo.jp/alicia/rule.html
- Embedded VRM permissions: use by everyone; commercial use allowed;
  redistribution governed by the linked model terms; violent and sexual usage
  disallowed.
- Project Nia applies the more restrictive published interpretation that
  corporate commercial use is not granted by these model terms. A commercial
  corporate distributor must obtain suitable model rights or replace the asset.

The Android application loads the appearance-adjusted derivative named
`nia_avatar_nia.vrm`. Project Nia's code and motion data do not claim authorship
of the Alicia mesh, textures, character, or rig.
